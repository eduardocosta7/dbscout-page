Privacy

Your client's database never leaves your machine

Zero telemetry. File paths, table contents, package names — none of it travels. The only four conversations with the network exist for the product, never for the data you're inspecting.

  • License — sends the key and the machine hash, only once you already have a saved license.
  • Update — only downloads the signed installer for a new version.
  • Error report — the text passes through a scrubber that swaps paths, package names and databases for placeholders before it leaves.
  • Installing an AI assistant — downloads the vendor's official CLI, only on click, and checks its hash before running it.

FAQ

Questions people ask before subscribing

How does the 3-day trial work?

Subscribing to either plan starts a 3-day window before the first charge — enough to try writing, cell editing and the AI assistants. Cancel within that window and you're never charged.

Can I cancel anytime?

Yes, no lock-in. Cancelling stops the next charge, and the license simply reverts to Free the next time it revalidates — no manual step, no support ticket.

Does it still work without internet?

Yes. Pro keeps working offline for up to 72 hours after the last check and warns you before it expires; a hard refusal from the license server drops it to Free immediately instead.

Is it safe to edit a client's production database?

Being honest: the real risk is editing while the app on the phone still has that same database open — returning the file underneath it can corrupt what the app is mid-write on. Outside that case, edits are scoped one cell at a time, by row, with type validation.

Can the AI assistant see my other files?

No. Every assistant runs boxed in to the database on screen only — no file, shell or network access, even the vendor's own tools are disabled. It refuses anything outside that, even if asked.
